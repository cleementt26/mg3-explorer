# MG3 Explorer

Showroom 3D interactif d'une MG3 Hybrid+ Luxury blanche, hébergé sur GitHub Pages.

- Quatre portes, capot et coffre animés
- Compartiment moteur et garnitures intérieures visibles
- Vues 3/4, avant, arrière, profil et dessus
- Rotation 360°, navigation tactile/souris, zoom et phares
- Modèle Web détaillé dérivé de la géométrie MG3 fournie

## Développement

Avec Node.js 22.12 ou ultérieur : `npm install`, puis `npm run dev`.

`npm run build` génère les fichiers statiques dans `docs/`.
